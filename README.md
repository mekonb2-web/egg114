# Christmas Show

This is a Python project created for EGG 114.

The program detects a guest and starts a Christmas Show. Santa dances up to 6 steps, and the show ends when Santa completes all 6 steps.

## Functions

- `system()` — Detects a guest.
- `santadance()` — Controls Santa's dance steps.
- `endshow()` — Ends the show and displays a Christmas tree.

## Project Goal

To demonstrate Python functions, conditions, loops, and file handling.
